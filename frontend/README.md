# Frontend

Интерфейс QUE. Текущий этап — работающая схема главной страницы.

```text
Шапка: QUE
──────────────────────────────────────
HeroCarousel: полноширинная фотолента тем
с активной карточкой по центру
──────────────────────────────────────
Заголовок выбранной ленты
Область вертикальной ленты (заглушка)
```

По умолчанию выбраны «Все новости». Это отдельное обзорное состояние,
а не шестая рубрика. CategorySelector подключает переиспользуемый
`src/components/ui/hero-carousel.tsx`: выбранная карточка центрируется
и раскрывается до полной высоты, соседние вдвое ниже и имеют общий верхний край.
Высота блока равна высоте раскрытой карточки (136–228 px в зависимости
от высоты экрана). В карусели видны только изображения и названия карточек,
без отдельного фона, заголовка, описаний, счётчика и кнопок. Общий фон страницы
следует за выбранной рубрикой: исходная фотография без серой подложки,
полупрозрачной вуали и цветовых фильтров.
Текст поверх фотографии светлый с тенью для читаемости.

Управление: нажатие на карточку, горизонтальное перетаскивание мышью или пальцем, колесо мыши / трекпад,
клавиши ← / → / Home / End. У краёв карусели прокрутка передаётся странице.
Вертикальные сенсорные жесты сохраняют прокрутку страницы. Tab перемещает
фокус без смены темы; скрытые карточки исключены из Tab-последовательности.
Выбор меняет заголовок и описание ленты; кнопка «Все новости» возвращает
обзорное состояние.

Размеры рассчитываются через ResizeObserver. Учитывается системная настройка
уменьшения движения. Автопереключение по умолчанию выключено; при включении
оно приостанавливается во время наведения, фокуса и перетаскивания, а при
уменьшении движения отключается. `hero-carousel-demo.tsx` — отдельный пример
с локальными демонстрационными изображениями проекта.

Карточки новостей и дополнительные функции на этом этапе не разрабатываются.

- `public/` — статические файлы.
- `src/pages/` — страницы портала.
- `src/components/` — переиспользуемые компоненты.
- `src/components/ui/` — базовые UI-компоненты, включая CategorySelector.
- `src/styles/` — общие стили.
- `src/mocks/` — явно обозначенные демонстрационные данные.

## Технологии и соглашения

React, TypeScript, Vite, Tailwind CSS 4, Framer Motion. Framer Motion управляет
перемещением фотоленты и сменой общего фона страницы. Высота карточек
и их затемнение используют CSS-переходы для устойчивого быстрого переключения.
Все зависимости уже установлены; дополнительная настройка shadcn/ui не нужна.

`@/` указывает на `src/`. Компоненты shadcn/ui размещаются в
`src/components/ui/`, стили — в `src/styles/globals.css`. Эти пути согласованы
в components.json, TypeScript и Vite. Физическая корневая папка `/components/ui`
не нужна: импорт `@/components/ui` разрешается в `src/components/ui`.

Настройка выполнена вручную по документации
[shadcn/ui](https://ui.shadcn.com/docs/installation/vite) и
[Tailwind CSS](https://tailwindcss.com/docs/installation/using-vite).
Добавление стандартного компонента в работающий контейнер:

```bash
docker compose exec frontend npx shadcn@latest add button
```

Команда выполняется из корня репозитория. Созданные файлы и изменения
package.json/package-lock.json сохраняются в frontend через подключённый каталог.

Основные команды Docker Compose описаны в корневом README. При наличии
Node.js 22.12+ или 24 можно работать без контейнера:

```bash
cd frontend
npm ci
npm run dev
npm run build
```
