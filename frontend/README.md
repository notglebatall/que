# Frontend

Интерфейс QUE. Текущий этап — работающая схема главной страницы.

```text
Шапка: QUE
──────────────────────────────────────
CategorySelector: неподвижная сетка
изображений с названиями рубрик
──────────────────────────────────────
Заголовок выбранной ленты
Область вертикальной ленты (заглушка)
```

По умолчанию выбраны «Все новости». Это отдельное обзорное состояние,
а не шестая рубрика. Все шесть вариантов видны сразу: шесть столбцов
на широком экране, три на планшете и два на телефоне. Карточки сохраняют
размер и положение при выборе; активная отмечена рамкой и галочкой.
Переключение доступно нажатием, клавишами Enter / Пробел и ← / → / Home / End.
Tab перемещает фокус без смены рубрики. Прокрутка и жесты не меняют выбор.

Выбор рубрики меняет единый фон всей страницы: фото и оттенок находятся
на фиксированном слое под шапкой, рубриками и новостной лентой. У сетки
нет отдельного фонового блока. Насыщенность фото и прозрачность белого слоя
настроены так, чтобы тема оставалась заметной. Светлые карточки и тёмный текст сохраняют
читаемость; при уменьшении движения фон переключается без анимации.

Карточки новостей и дополнительные функции на этом этапе не разрабатываются.

- `public/` — статические файлы.
- `src/pages/` — страницы портала.
- `src/components/` — переиспользуемые компоненты.
- `src/components/ui/` — базовые UI-компоненты, включая CategorySelector.
- `src/styles/` — общие стили.
- `src/mocks/` — явно обозначенные демонстрационные данные.

## Технологии и соглашения

React, TypeScript, Vite, Tailwind CSS 4, Framer Motion. Переключатель рубрик
использует CSS Grid без измерений размеров и анимации перемещения карточек.
Framer Motion используется для плавного изменения общего фона страницы;
учитывается системная настройка уменьшения движения.

`@/` указывает на `src/`. Компоненты shadcn/ui размещаются в
`src/components/ui/`, стили — в `src/styles/globals.css`. Эти пути согласованы
в components.json, TypeScript и Vite. Физическая корневая папка `/components/ui`
не нужна: импорт `@/components/ui` разрешается в `src/components/ui`.

Настройка выполнена вручную по документации
[shadcn/ui](https://ui.shadcn.com/docs/installation/vite) и
[Tailwind CSS](https://tailwindcss.com/docs/installation/using-vite).
Добавление стандартного компонента в работающий контейнер:

```bash
docker compose exec frontend npx shadcn@latest add button
```

Команда выполняется из корня репозитория. Созданные файлы и изменения
package.json/package-lock.json сохраняются в frontend через подключённый каталог.

Основные команды Docker Compose описаны в корневом README. При наличии
Node.js 22.12+ или 24 можно работать без контейнера:

```bash
cd frontend
npm ci
npm run dev
npm run build
```
