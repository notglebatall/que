# QUE

Новостной портал для сотрудников Центрального банка Российской Федерации.

## Принятая структура

Один репозиторий с независимыми каталогами frontend, backend и базы данных.

```text
que/
├── frontend/
│   ├── public/
│   ├── src/
│   │   ├── pages/
│   │   ├── components/
│   │   │   └── ui/
│   │   ├── styles/
│   │   └── mocks/
│   ├── Dockerfile
│   └── .dockerignore
├── backend/
│   └── README.md
├── db/
│   └── README.md
├── compose.yaml
├── compose.deploy.yaml
├── .env.example
├── .gitignore
├── AGENTS.md
└── README.md
```

Структура создана. `compose.yaml` — локальная разработка, `compose.deploy.yaml` —
серверная сборка frontend; backend и db пока содержат только README.

## Границы приложений

- `frontend/` — пользовательский интерфейс. Первый этап — главная страница
  с рубриками и новостной лентой на явно обозначенных демонстрационных данных.
- `backend/` — заготовка для будущего API; стек пока не выбран.
- `db/` — заготовка для будущих настроек БД и инициализации; СУБД пока не выбрана.

Запуск проекта — через Docker Compose. В целевой конфигурации предусмотрены
сервисы `frontend`, `backend` и `db`. На первом этапе запускается только
`frontend`, без зависимости от остальных сервисов.

## Запуск и проверка

Нужны Docker Engine и Docker Compose. Устанавливать Node.js на хост не требуется.

```bash
docker compose up --build
```

Открыть http://localhost:5173. Исходники frontend подключены в контейнер,
изменения подхватываются автоматически. npm-зависимости находятся в отдельном
именованном томе и устанавливаются из package-lock.json при запуске.
Чтобы изменить порт, скопируйте `.env.example` в `.env`.

```bash
# Проверить конфигурацию контейнеров
docker compose config --quiet

# Проверить TypeScript и собрать frontend
docker compose run --rm --no-deps frontend npm run build

# Только проверка TypeScript
docker compose run --rm --no-deps frontend npm run typecheck

# Остановить локальное приложение
docker compose down
```

Автоматизированного набора тестов пока нет. При проверке UI нужно пройти
выбор всех рубрик, возврат ко всем новостям, клавиатурную навигацию,
вертикальную прокрутку и мобильную компоновку.

## Развёртывание на сервере

Исходники стенда хранятся в Git: https://github.com/notglebatall/que, ветка `main`.
При первом развёртывании:

```bash
git clone --branch main https://github.com/notglebatall/que.git que
cd que
```

Обновление и пересборка из каталога проекта на сервере:

```bash
git pull --ff-only origin main
docker compose -f compose.deploy.yaml up -d --build --wait
docker compose -f compose.deploy.yaml ps
docker compose -f compose.deploy.yaml logs --tail=50 frontend
```

Серверная конфигурация собирает приложение с проверкой TypeScript и отдаёт
готовые файлы через nginx внутри контейнера frontend. Исходники и node_modules
в работающий контейнер не подключаются. Настроены проверка работоспособности
и автоматический перезапуск.

По умолчанию опубликован порт 8080; изменить его можно переменной `QUE_HTTP_PORT`
в `.env`. Для разработки используется отдельная команда `docker compose up --build`.

## Frontend

Frontend использует React, TypeScript, Vite, Tailwind CSS и Framer Motion.
Настроена совместимость с shadcn/ui: components.json, CSS-переменные темы,
хелпер cn и алиас @/. Точные версии зависимостей фиксирует package-lock.json.

Переиспользуемые UI-компоненты размещаются в `frontend/src/components/ui/`.
Алиас `@/` указывает на `frontend/src/`,
чтобы работали импорты вида `@/components/ui/category-selector` и `@/lib/utils`.

Первый UI-прототип: светлая главная страница, неподвижная сетка рубрик сверху
и область вертикальной ленты ниже. Рубрики: **Экономика, Политика, Финансы,
Технологии, Прочее**. Отдельный пункт «Все новости» открывается по умолчанию.
Выбор меняет фон, отметку активной карточки и заголовок области ленты.
Размеры и расположение карточек при переключении сохраняются.

Карточки новостей, поиск, сохранение, фильтры, счётчики и страницы материалов
в текущую версию не входят. Область ленты обозначена как схема; реальные
новости не используются. Фотографии рубрик — демонстрационные, хранятся
локально; источники перечислены в frontend/public/images/README.md.
